# मायेचं | HOMESPUN PRODUCTS

A premium, mobile-first product **enquiry** web app for a traditional Maharashtrian homemade snacks business.

> **This is NOT an e-commerce application.** No payments, no cart, no login, no order tracking.
> The entire ordering experience happens via WhatsApp.

---

## ✨ Features

- 9 traditional Maharashtrian snacks with authentic photos
- Bilingual (Marathi + English) product cards
- Beautiful bottom-sheet quantity selector (0.5 kg – 100 kg, decimals supported)
- Live estimated-total calculation
- One-tap WhatsApp enquiry with pre-filled message
- Sticky WhatsApp access (header, FAB, drawer, contact section)
- Slide-out mobile menu + bottom navigation
- FSSAI registration + contact details prominently displayed
- Works **without** Supabase credentials (local fallback)
- Fully responsive (360px → 1440px)
- Accessible (focus states, reduced motion, ARIA labels, skip link)
- SEO meta tags + Open Graph
- Zero-build, deployable straight to Vercel
